# ADR 0006: 서버 권위와 비밀 DTO

- 날짜: 2026-10-06
- 상태: 제안 — 사용자 설계 승인 대기

## 배경

client 입력과 시간은 변조 가능하다.

## 결정안

online secret Board/seed는 서버만 보유, intent만 입력, 매치 직렬 처리, public DTO만 응답한다.

## 대안

브레인스토밍의 client seed 전송은 정답 노출 위험으로 채택하지 않는다.

## 영향과 검증

네트워크 지연은 존재하고 동일 판 정보 공유는 완전 차단 불가. 데일리/로컬 신뢰 분리.
