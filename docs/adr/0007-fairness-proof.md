# ADR 0007: 관측 기반 간파 증명

- 날짜: 2026-10-06
- 상태: 채택 — 사용자 구현 시작 지시, PR 병합 승인 별도

## 배경

미래 모순은 추측 없는 간파의 충분조건이 아니다.

## 결정안

모든 가능한 관측 모델에서 확정 안전 행동/확정 lie 식별 경로를 증명하고 두 overlay를 함께 검증한다. budget 초과는 거절한다.

## 대안

정답 기반 시뮬레이션·모호한 모순·타이머 자동 정정은 공정성 요구를 만족하지 못하거나 규칙 변경이다.

## 영향과 검증

생성/검증이 비현실적일 수 있다. M1의 E4를 출시 차단 검증으로 두고 실패시 사용자에게 규칙 재설계 제안.
