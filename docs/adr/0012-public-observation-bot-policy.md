# ADR0012: 공개 이력으로만 행동하는 세 난이도 봇

- 날짜: 2026-10-07
- 상태: 채택 — #8, FR06, TS11. 선행 #7은 PR34로 병합·종료했다.

## 결정

BotPolicy는 공개 Projection·Clock·별도 RandomSource만 받는다. 숨은 Board/seed/상대 cells/overlay 참조를 받지 않는다. 공개 전략의 본인 숫자 이력을 재생하고 확정 lie 지목→게이지 공격→확정 safe open 순서로 행동한다. safe 셀에 flag가 있으면 먼저 unflag한다. 동일 관측/Clock/RNG의 의도는 숨은 보드가 달라도 같다. 확정 safe가 없거나 예산을 초과하면 대기하며 추측하지 않는다.

난이도 수치는 단일 game-rules.toml에 둔다. 첫 프로필은 쉬움900ms·지목1500ms·5000노드/12칸/256제약, 보통500ms·800ms·50000/18/512, 어려움180ms·250ms·200000/22/1024다. 결정 간격·지목 지연·추론 메모리/노드 예산으로 난도를 구분하며 인간 재미·승률 검증 전의 튜닝값이다. 기절/카운트다운/종료/시각 역행은 행동하지 않는다. 실패한 공격을 매 tick 반복하지 않고 본인 숫자 이력 또는 상대 공개 progress가 바뀐 뒤 다시 시도한다.

해당 난이도에서 완전히 증명한 safe 계획은 최대256칸의 메모리에 보존한다. 이후 frontier의 비용이 커져도 앞서 확정한 safe를 잊고 추측하지 않는다. 새 관측으로 열린 셀만 제거하며 숫자 공격과 flag는 불변 지뢰 배치를 바꾸지 않는다.

**공개 전략 이력 분류에는 세 난이도 모두 canonical solver budget을 사용한다.** 난이도 budget으로 후보 등록 증거까지 약화하면 서버가 등록한 셀을 봇이 미등록으로 해석해 거짓 숫자를 truth로 취급할 수 있다. 따라서 공개 규칙의 합법적 세계를 복원하는 이력 ledger와, 난이도별 다음 safe 계획의 제한된 탐색을 분리한다. 논리 숫자는 공개 증거로만 계산하며 작은 budget에서 중간 모델 결과를 반환하지 않는다. 이 ledger/추론은 #12/#16에서 bounded worker에 연결하고 주 입력 경로에 두지 않는다.

snapshot rules/hash·관측·flag 길이·이력 prefix/새 배치·revision을 확인한다. 현재 관측으로 이력 없이 새 ledger를 만들지 않으며 변경된 규칙·뒤로 간 이력을 거절한다. 내부 safe/mine/truth/lie 결론을 public DTO로 보내거나 UI에 자동 표시하지 않는다. 로컬 봇은 practice이고 공식 서버 대전과 구분한다.

## 검증

Clock/RNG fake로 같은 관측의 결정·세 프로필 간격·지목 지연·flag 복구·공격 실패 후 진행·stun/countdown/end·예산/막힘 대기·이력 오류를 확인한다. 실제 인증 보드의 결정 실행과 native/WASM 비교는 각 이슈에서 별도 기록한다. 정답 Board는 테스트의 독립 대조/실제 open에만 사용한다.
