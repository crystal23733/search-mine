# ADR0070 · 실제 저장소·쿠키 고지

- 상태: 채택 · 승인된 FR01/10/11/13 · NFR01/02/06/07/08 · #150, 상위 #21
- 선행: #20/PR146·#148/PR149 병합/CLOSED, develop2c4a62d 확인
- 시나리오: TS18/19/24/26/31/35/36

## 목적과 범위

설정의 한 문장 고지는 현재 튜토리얼/캐시 선호·로컬 대기 제출과 인증 쿠키/삭제 범위를 충분히 안내하지 않는다. 실제 구현을 근거로8언어 기술 고지를 제공한다. 개인정보/약관의 법적 근거·운영자/연락처·국외 이전/미성년자 내용과 실제 CMP/ads.txt 검수는 #21/#147의 필수 후속이다. 본 고지를 공개 정책 검수나 CMP 동의로 취급하지 않는다.

모든 화면의 footer에 언어별 /storage 링크를 둔다. StoragePage와 기존 설정 dialog가 같은 읽기 전용 StorageNotice organism을 재사용한다. 공통 토큰/semantic 목록을 쓰며 좁은 화면에서 본문과 dialog가 스크롤된다. 긴 고지 dialog는 제목으로 초기 초점을 보내 첫 안내부터 보이며, Tab으로 닫기에 이동/스크롤하고 Escape/닫기로 opener에 초점을 복구한다. 열기/닫기는 저장소나 쿠키를 읽어 열거하거나 변경하지 않고, 동의/로그인/대기 전송/삭제를 실행하지 않는다. 별도 동의 승인 버튼과 자동 첫 화면 차단을 추가하지 않는다.

## 현재 코드와 고지 계약

| 범주 | 구현 근거와 고지 |
|---|---|
| 기기 설정 | preferences/learning/offline의 언어·접근성·튜토리얼 완료/건너뛰기·캐시 사용 선택. 자동 만료 없이 브라우저 사이트 데이터를 지울 때까지 유지될 수 있음 |
| 로컬 데일리 | daily-records의 replay/미검증 결과·대기 목록. 최근 날짜 최대30개, 새 기록으로 오래된 항목 제거 또는 설정에서 기록 지우기. 로컬 연습의 대기 결과는 현재 계정에 명시 제출. 공식 데일리는 시작 확인한 계정으로 완료 때 자동 제출하며 구분해 고지 |
| 오프라인 캐시 | service-worker의 공개 앱/언어/WASM 정적 파일. 업데이트·설정 캐시 지우기·브라우저 제거까지 유지, 계정 API/온라인 숨은 정답 저장 안 함 |
| 보안 쿠키 | auth/http·browser의 요청 보호/인증 거래용5분 쿠키, 로그인 유지용 최대30일 쿠키. HttpOnly/Secure, 브라우저 설정에서 제거 가능; JS 저장소에 로그인 token을 복사하지 않음 |
| 선택 처리 | 현재 광고·선택 분석용 태그와 저장소는 비활성. 읽기/닫기·OAuth·게임을 광고/분석 동의로 간주하지 않음. 실제 CMP/선택 adapter가 추가되면 고지와 검증도 함께 갱신 |

설정의 기록 지우기는 로컬 결과/대기를, 캐시 지우기는 공개 오프라인 파일을 제거한다. 두 동작은 로그인/서버 계정 삭제가 아니다. 로그아웃은 현재 세션을 종료하며 서버 계정/기록 삭제와 다르다. 서버 계정 삭제는 계정 설정의 별도 확인/최근 인증을 따르고, 기기 설정과 공개 캐시 정리는 각각의 제어를 따른다. 브라우저 사이트 데이터 삭제는 로그인·설정·튜토리얼·로컬 기록·캐시에 영향을 줄 수 있다. 저장소 사용 불가 시 설정/로컬 기록의 메모리 대체와 새로고침 후 유실 가능성을 안내한다.

## 검증

실제 App DOM에서 footer/고지 route/설정 dialog 내용과 읽기의 무부작용을 Red→Green으로 확인한다.8언어 모두 번역된 범주와 유지/삭제 안내를 제공하고, 실제 Chromium PC/mobile에서 좁은 화면/초점 복구·저장소 차단·서버 실패에도 고지와 로컬 연습이 작동하는지 검사한다. 기존 기록/캐시/로그아웃/삭제 행동 검증을 유지한다. 문서/Mermaid·관련 웹/full·코드 리뷰·최신6checks/정확head 병합을 실제 기록한다. #83/#141과 외부 #147의 완료를 대신하지 않는다.
