# ADR0077 · 처음 배우는 사용자의 튜토리얼 기초 안내

- 상태: 채택 · 최신 사용자 요청과 승인된 FR08/11·NFR01/02/05/06/08 · #163
- 선행: #12 CLOSED, #161/PR162 developbe4096c 병합·CLOSED
- 시나리오: TS13/18/19/20/26/30

## 문제와 범위

현재 첫 방문 튜토리얼은 실제 Rust/WASM 학습 판에서 열기→공격→바뀐 숫자 열기→지목/반사를 실행하며 skip/replay와8언어·무계정 경계를 제공한다. 그러나 처음 안내부터 숫자2로 두 지뢰를 증명하라고 하므로 지뢰찾기를 모르는 사람은 숫자·대각선 이웃·깃발·모드의 의미를 알기 어렵다. 최신 사용자는 처음 하는 사람도 할 수 있는 튜토리얼을 확인하고 가능한 보완을 진행하라고 요청했다.

새 규칙이나 학습 판을 만들지 않는다. 기존 공개 TutorialView와 RuleEngine을 그대로 사용하고 규칙을 TS에 복제하지 않는다. 읽을 수 있는 기초 설명과 기존 안내 버튼의 역할을 추가한다. 실제 참여자의 이해와30초 목표는 #27의 관찰이며 자동 완료와 구분한다.

## 결정

공통 molecule `PlayBasics`를 튜토리얼 안내 카드와 규칙 화면에서 재사용한다. 다음 내용을8언어로 제공한다.

1. 지뢰 없는 안전 칸을 여는 목적, 원래 숫자는 대각선을 포함한 주변 최대8칸의 지뢰 수라는 의미.
2. 깃발은 닫힌 칸에 남기는 메모이며 지뢰 판정이나 승리 조건을 대신하지 않는다는 점.
3. 보드 아래 열기/깃발/지목 모드를 고른 뒤 클릭/탭하는 기본 조작.
4. 공격으로 숫자가 바뀔 수 있으므로 깃발이나 추측 대신 공개 숫자의 논리로 열린 거짓 숫자를 지목한다는 점.

튜토리얼의 첫 단계에는 기초 설명이 펼쳐진다. 첫 실습으로 단계가 진행되면 접어서 다음 안내와 보드를 볼 수 있게 한다. 이후 학습자는 언제든 다시 펼칠 수 있다. 펼치기/접기는 native details/summary의 키보드·터치 제어를 쓰며 현재 학습 단계·게이지·완료/skip 저장·초대 URL을 바꾸지 않는다. 언어 변경도 펼침 상태와 학습을 유지한다. replay는 새 학습 인스턴스와 함께 기초 설명을 다시 펼친다. 규칙 화면에서는 기본적으로 펼쳐서 읽는다.

튜토리얼에 안내 버튼 또는 보드에서 같은 동작을 실행할 수 있다는 문장을 추가한다. 기존 단계 버튼·보드·잘못된 동작의 거절·완료/skip/replay를 유지하며 새 필수 확인이나 추가 저장 필드를 만들지 않는다. 학습3×3/게이지1과 일반16×16/게이지20 구분은 기존 Rust 공개 규칙과 안내를 따른다. UI에 새 정답·숨은 mine/lie 상태를 넣지 않는다.

네이티브 summary는44px 이상 제어 영역·초점 표시를 제공하고 긴 번역은360px 안에서 줄바꿈한다. 공통 토큰과 기존 Card/MatchLayout을 사용한다. 계정·쿠키·CMP·광고·선택 이벤트·네트워크 요청은 추가하지 않는다. #83의 SW/업데이트/예산/retry/network 설정과 의존성은 변경하지 않는다.

실제360px 화면 검토에서 한국어 보드 모드의 두 글자가 각각 다른 줄에 표시되는 것을 확인했다. 모드 버튼은 이름 전체가 한 줄에 들어갈 최소 폭을 갖고, 필요하면 버튼 자체가 다음 줄로 이동하게 한다. 글자가 버튼 밖으로 넘치거나 터치 영역이44px 미만이 되지 않게8언어의 실제 텍스트 배치를 검사한다. 공통 보드 스타일의 표시 보완이며 입력/규칙은 유지한다.

## 검증과 남은 일

안내가 없는 현재 화면에 행동 검사를 먼저 추가해 실제 Red를 확인한다. 접기/재열기·첫 동작 후 접힘·언어 전환·replay/skip과 규칙 화면 공유를 DOM에서 검증한다. 실제 WASM의 PC/mobile 학습 완료·공격/지목/반사와8언어·360px·summary 키보드·저장소 거부/초대 보존을 확인한다. 프로젝트 관련 전체 검사·문서/Mermaid·코드 리뷰·최신6checks와 정확head/CLEAN을 확인해 develop에 병합한다.

[관찰 준비](../verification/12-tutorial-observation-guide.md)에 지뢰찾기 경험 여부와 기초 설명 사용·숫자/깃발/지목 설명을 추가한다. 시간은 첫 안내부터 계속 재며 기초 읽기 시간을 빼서30초 성취로 만들지 않는다. 실제 사람의 표본/원자료·재미·실기기와 외부 OAuth/CMP·운영 검증은 기존 이슈에 남긴다.
