# ADR0079 · 다음 행동이 먼저 보이는 튜토리얼

- 상태: 채택 · 사용자 실제 화면 피드백과 승인된 FR08/11 · #167
- 선행: #163 CLOSED, 최신 develop `50d31ae7`
- 시나리오: TS13/18/19/20/26/30

## 관찰과 결정

사용자는 한국어 튜토리얼에서 무엇을 해야 할지 모르겠고 문장이 어색하다고 보고했다. 실제 화면에서 긴 기초 설명이 현재 과제와 버튼보다 먼저 나타나며 PC에서는 오른쪽 좁은 카드 아래로 버튼이 밀린다. 보드에도 안내의 C3가 표시되지 않는다.

튜토리얼은 PC와 모바일 모두 현재 단계 제목·짧은 설명·주요 버튼을 게임판보다 먼저 보여 준다. 기초 설명은 같은 페이지에서 펼쳐 읽을 수 있지만 현재 과제 뒤에 놓는다. 처음 펼침·단계 진행 뒤 자동 접힘·언어 전환/재학습 상태는 ADR0077을 유지한다. 일반 대전의 배치는 바꾸지 않는다.

Rust가 이미 공개한 expected에 cell이 있으면 그 칸에 좌표 배지와 구별되는 테두리를 표시한다. 초기 키보드 선택 위치도 그 칸으로 맞추되 사용자 초점을 강제로 옮기지 않는다. 단계 카드에는 위에서 몇 번째/왼쪽에서 몇 번째인지 8언어로 설명한다. 공격 단계와 완료에는 대상 칸 표시가 없고 지목 단계의 보드 모드는 사용자가 직접 고르는 기존 조작을 유지한다. 안내 버튼은 기존 expected 동작을 그대로 제출한다. UI에서 다음 정답·지뢰·거짓 상태나 규칙을 계산하지 않는다.

한국어 기초/단계 문구는 안전한 칸 열기→게이지 사용→바뀐 숫자 확인→숫자 비교/지목 순으로 짧게 안내한다. ‘공개 증거’, ‘기절 반사’ 같은 내부 용어는 사용자가 할 행동과 눈으로 보는 결과로 설명한다. 논리로 지목해야 한다는 규칙과 원래 숫자/공격 뒤 표시 숫자의 구분은 유지한다.

## 검증

현재 단계가 기초 설명보다 먼저 나오고 정확한 expected 셀만 표시되는 DOM 행동 검사의 Red를 먼저 확인한다. 실제 WASM PC/360px 모바일에서 첫 버튼이 스크롤 없이 보이고 강조 좌표의 보드 입력과 안내 버튼이 같은 진행을 만들며 공격 시 표시 제거·reveal/accuse 표시 이동·완료 제거·replay 복원을 검사한다. 한국어 및 8언어 전환·키보드 기초 펼침·잘못된 동작 거절·초대/return 보존·무계정·광고0을 유지한다. 사람의 이해·30초 성취와 자동 검증은 구분한다.
