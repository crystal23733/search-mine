# ADR0094 · 튜토리얼 소개 문서와 명시적 학습 진입

- 상태: 채택 · #204(상위23) · FR08/11/12/13·NFR01/02/05/06/08 · TS13/18/19/20/23/26/30/31
- 승인 근거: 승인된 설계10의 튜토리얼 소개·FR08/11, 2026-10-07 전체 순차 위임/외부 입력 이연, 현재 사용자의 진행 지시. 새 게임 규칙/사업 범위는 추가하지 않는다.
- 선행: #202/PR203 MERGED/CLOSED · develop e54ebd8.

## 결정

`/{locale}/learn`은 로그인 없이 읽는8언어 소개다. 학습 내용(열기·공격·지목)과 기존 PlayBasics를 공통 Card/토큰/semantic 문서로 보여 준다. 읽기/언어 변경은 학습 완료·건너뛰기 상태를 쓰지 않고 WASM/보드/게임을 초기화하지 않는다. 실제 연습은 명시 시작 링크의 기존 `/{locale}/tutorial`에서 한다. 기존 홈 첫 방문 자동 튜토리얼·학습 단계/상태 저장/재학습·계정/초대 복귀 계약은 그대로다.

소개 페이지의 진입/시작/규칙 복귀는 locale을 고정한 plain href로 새 문서를 연다. query/hash/사용자 입력을 복사하지 않고 임의 외부 주소/초대/계정 상태를 인수로 받지 않는다. 기존 규칙 화면의 직접 재학습 버튼은 유지하며 소개 링크를 추가한다. 공통 footer와 정적 공개 문서의 고정 링크로 소개를 찾을 수 있다. 기존 auth bootstrap은 앱 공통 수명이며 소개에서 별도 계정을 만들거나 로그인 API를 호출하지 않는다.

소개는 SEO 공개 allowlist에 포함하고 실제 /tutorial은 계속 게임/noindex다. ADR0093의 설정 origin/URL0·privatequeryhash/공통 head·불변 preview 계약을 적용해 4종×8=32개 HTML/sitemap을 만든다. 새 title/description/단계 제목/시작·반복 안내를8언어로 작성하며 기본 조작/실제 규칙 수치는 기존 메시지/Rust 원천을 재사용한다. 전문 번역/사람 이해도 검수를 대신하지 않는다.

광고 allowlist는 홈/규칙 그대로다. 소개도 광고 제외이며 SDK가 있는 문서의 소개 진입은 새 문서여야 한다. 소개에서 게임으로 명시 이동한 뒤에도 게임 광고0/무계정 연습을 유지한다. SDK/동의·학습/온라인 게임 규칙을 재정의하지 않는다.

## 검증

실제 구현 전에 App/HTTP Red를 확인한다. new/skipped/complete 및 저장소 거부 상태의 소개 유지·학습 쓰기0/core초기화0·8언어 문구·광고0·clean href와 기존 홈의 자동 학습을 검증한다. JS-off dev/preview8소개/32문서·configured metadata/sitemap·private URL 반영0, PC/mobile360·키보드/긴문구, 실제 명시 시작→기존보드(숫자/기초 단계) 진입과 상태 수명을 확인한다. 전체관련 CI/coverage·실제 코드리뷰·정확 head 병합으로 마친다. 실제 도메인/검색 최종 문서·정책/전문 번역/사람 검수와 #83은 별도다.
