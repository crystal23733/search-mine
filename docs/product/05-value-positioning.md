## 포지셔닝 후보

| 문장 | 근거 / 뒷받침 메시지 | 위험 |
|---|---|---|
| 상대에게 거짓말하는 지뢰찾기 | 숫자 조작과 반사 / 논리로 찾아 반격 | 불공정한 게임처럼 들릴 수 있음 |
| 4분 두뇌 대전 | 짧은 판 / 설치 없이 친구와 플레이 | 일반 웹게임과 구분 약함 |
| 속아도 논리로 되찾는 승부 | 간파 가능한 공격 / 지목하면 반사 | 증명과 쉬운 설명 필요 |
| 오늘의 판, 내일의 재대결 | 데일리 공유 / 매일 같은 도전 | 핵심 1:1을 약하게 표현 |
| 친구와 브라우저 한 판 | 초대 링크 / 계정 없이 입장 | 기존 대전작도 제공 가능 |

우선 문구는 “상대 숫자를 속이고, 논리로 간파하는 4분 웹 대전”이다. 공정성 검증을 통과하기 전 “항상 논리로 이긴다”는 확정 광고를 하지 않는다. 다섯 경쟁작의 실제 포지셔닝은 02 문서를 참조한다.

## 결정 사항

가치의 중심은 공격/지목 경험이다. 무광고·세계 최초·치트 불가능이라는 주장은 사용하지 않는다.
