| 블록 | 현재 가설 |
|---|---|
| 문제 | 친구 대전 준비가 길다; 추측 패배가 싫다; 기존 솔로에 새 긴장이 부족하다 |
| 해결 | 링크 방/최소 OAuth 계정·로컬 무계정 연습; 노게스·간파 가능한 공격; 4분 공격과 지목 |

| 세그먼트 | 친구 초대 사용자 우선; 데일리·숙련 사용자 다음. TAM 미측정 |

| 수익 | 메뉴 배너와 결과 전면 광고. 승인·채움률·동의율·유효 노출에 좌우됨 |
| 비용 | 기존 미니 PC 전력, 도메인, 교체/백업 여유. 신규 장비·인건비 별도 |
| 핵심 지표 | 주간 반복 대전 사용자; 튜토리얼 완료; 재대결; D7; 월 광고 순수익/현금 운영비 |

## 경제 가정과 검증

고정비는 [07-monetization.md](07-monetization.md)의 시나리오로만 계산한다. 유료 유입비는 초기 0원이나 운영자의 시간이 공짜인 것은 아니다. 현금 손익과 인건비를 포함한 경제 손익을 따로 기록한다. 광고 승인 전 수익은 0원으로 계획한다.

상위 가정은 재미, 거짓말 간파 가능성, 광고 후 재대결 유지, 홈서버 용량이다. 순서대로 [실험 계획](11-experiments.md)에 대응한다.

## 결정 사항

기능 범위를 수익 모델에 맞춰 좁힌다. 유료 상품·외부 게임 포털·배틀로얄은 추가하지 않는다.

## 열린 질문

실측 평균 소비전력, 도메인 갱신비, 통신사 서비스 제공 약관을 공개 전에 확인한다.
