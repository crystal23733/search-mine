# 08. SWOT

> 적용: pm-product-strategy:swot-analysis · 입력: [경제 모델](07-monetization.md)

| 강점 S | 약점 W |
|---|---|
| 짧고 설명 가능한 훅; 브라우저 접근; 낮은 증분 현금비; 공통 Rust 규칙; 게스트·다국어; 범위가 고정됨 | 재미 미검증; 동접 없음; 홈서버 단일 장애점; 간파 알고리즘 난도; 8언어 검수 부담; 1인 운영 |

| 기회 O — 가설 | 위협 T |
|---|---|
| 친구 대전 공유; 데일리 습관; 짧은 영상 소재; 숙련자 공정성 테스트; 설치 없는 모바일; 소규모 커뮤니티 | 기존 지뢰찾기 습관; 공격 불공정 인식; 전력·회선 장애; 광고 승인 실패; 자동 풀이; 국가 간 지연 |

## 교차 실행

| 조합 | 행동 / 담당 | 지표 / 기한 |
|---|---|---|
| S×O | 친구 링크와 반사 설명을 우선 검증 / 사용자+PM | E1·E2, 싱글 플레이 검증 완료 시 |
| W×T | 간파 증거가 없는 공격은 거절 / 엔지니어 | 반례 0건, M1 출구 |
| W×O | 사람 대기 대신 표시된 봇 제공 / 엔지니어 | 10초 백필, M3 출구 |
| S×T | 운영비·유효 광고 노출을 자체 집계 / 사용자 | 28일 현금비 회수, M6 |
| W×T | 오프라인 모드와 백업 복구 검증 / 사용자+엔지니어 | 복구 훈련 성공, 공개 전 |

## 결정 사항

확장 기능 대신 공정성과 짧은 여정에 자원을 쓴다. SWOT의 기회는 시장 크기의 증거가 아니다.

## 열린 질문

홈서버 사양과 지역별 지연, 운영 가능한 주당 시간을 확인해야 한다.
