# 09. North Star Metric

> 적용: pm-marketing-growth:north-star-metric · 입력: [SWOT](08-swot.md)

광고 모델은 Attention game이지만 체류 시간을 늘리기보다 반복해서 선택하는 즐거움을 측정한다.

**NSM: UTC 주간에 튜토리얼을 제외한 정상 1:1 대전을 2판 이상 완료한 고유 계정 수.** 봇 대전 포함, 로컬 오프라인은 검증되지 않은 별도 집계, 조기 포기·서버 장애 취소는 제외한다. 계정 삭제·연결하지 않은 여러 OAuth 계정으로 동일인 중복이 생길 수 있음을 표기한다.

| 검증 기준 | 판단 |
|---|---|
| 쉬운 이해 | 다시 플레이한 사람 수 |
| 고객 중심 | 반복 선택한 대전 가치 |
| 지속 가치 | 주간 반복 사용을 관측 |
| 비전 정렬 | 짧은 논리 대전의 반복 |
| 수량화 | account_id별 정상 완료 수로 계산 |
| 행동 가능 | 학습·대기·재대결 개선으로 영향 |
| 선행성 | 재방문·광고 기회를 예측할 가설; 상관 검증 필요 |

입력 지표는 튜토리얼 완료율, 최초 정상 대전 완료율, 첫 결과 후 10분 이내 재대결률, 친구 초대 입장률, D7이다. 분모·이벤트는 [20-metrics.md](20-metrics.md)에서 고정한다.

가드레일은 간파 불가 공격 0건, 플레이 중 광고 0회, 장애 취소율, p95 처리시간, 광고 후 재대결 변화다. 초기 2주 목표는 E2 참여자 10명 중 6명 이상 재대결 선택이며 모집단 성장 목표는 베이스라인 관측 뒤 결정한다.

## 결정 사항

매출·PV·전체 플레이 시간은 NSM으로 쓰지 않는다. 봇/사람과 언어별 분해를 함께 본다.

## 열린 질문

계정 중복·동의 거부로 생기는 측정 편향을 베타에서 평가한다.
