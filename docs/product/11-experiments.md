# 11. 가정 검증 실험

> 적용: pm-product-discovery:brainstorm-experiments-new · 입력: [가정](10-assumptions.md)
> 작은 표본의 판정 기준이며 통계적 시장 검증을 뜻하지 않는다. 외부 모집/메시지 발송은 사용자가 한다.

| ID | XYZ 가설 | 방법 / 표본 | 성공 / 중단 | 시점 |
|---|---|---|---|---|
| E1 | 처음 보는 친구 대전 사용자 80%가 30초 설명 후 지목을 올바르게 한다 | 종이 보드·화면 초안 10명, 진행자 도움 횟수 기록 | 8명 성공, 6명 미만이면 설명 재설계 | 코드 없이 가능 |
| E2 | 10명 중 60%가 첫 대전 뒤 자발적으로 재대결한다 | 승인 후 봇/친구 프로토타입, 1인 3판 | 6명 재대결, 4명 미만이면 훅 재설계 | M2/M3 |
| E3 | 데일리 완료자 5%가 공유 버튼을 누른다 | 공유 카드 예시 비교 후 실제 100완료 관측 | 클릭≥5%, 유입은 별도 지표 | M2 이후 |
| E4 | 모든 적용 공격이 안전한 간파 경로와 증거를 가진다 | 승인 후 코어 proptest·작은 판 전수 검사·수동 풀이 | 반례 0, 반례 1개면 공격 기능 차단 | M1 출구 |
| E5 | 28일 순 광고수익이 같은 기간 현금 운영비를 충당한다 | Google 승인 후 실 정산·전력계 관측 | R≥C; 미달이면 배치 개선·규모 동결 | M6 |

E1은 설명 영상/종이 보드/수동 진행 방식으로 각각 이해, 첫 클릭, 시간 투자를 비교할 수 있다. E2는 의견 대신 실제 한 판 더 선택을 기록한다. E3는 클릭과 신규 첫 판 전환을 구분한다. 광고를 추가한 E2에서는 재대결률 하락 5%p 이내를 가드레일로 둔다.

실험 결과에는 모집 경로, 언어, 숙련도, 표본 수, 관찰 기간, 원자료 보관 위치와 실패 사례를 남긴다. 성공 기준을 결과를 본 뒤 바꾸지 않는다. 기술 스파이크는 별도 사용자 승인 후 `spikes/`에서 수행한다.

## 결정 사항

검증 실패 시 수치나 설명을 재설계하고 PRD·ADR부터 고친다. 새 모드나 결제로 대체하지 않는다.

## 열린 질문

테스터 모집 가능 인원·주당 검증 시간·광고 승인 여부는 미확인이다.
