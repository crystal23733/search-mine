# 13. GTM과 성장 루프

> 적용: pm-go-to-market:gtm-strategy + growth-loops · 입력: [OST](12-ost.md)

## 첫 채널과 메시지

친구 그룹에는 “링크로 4분 두뇌 대전”, 숙련 커뮤니티에는 “간파 가능한 숫자 공격의 공정성 검증 참여”, 창작자에게는 “반사와 역전이 보이는 짧은 승부”를 전달한다. 개발자가 실제 허용 규칙을 확인해 직접 게시하며 에이전트가 자동으로 DM·이메일을 보내지 않는다.

## 루프 평가

| 순위 / 종류 | 메커니즘 | 적합성과 제한 |
|---|---|---|
| 1 Viral | 데일리 완료→카드 공유→링크 유입→첫 판 | 자연스러운 결과물. 신규 활성화까지 추적 |
| 2 Collaboration | 친구 방→초대→대전→재대결 | 실제 협업이 아닌 친구 연결 루프. 1:1 제품에 적합 |
| 3 Usage | 데일리→개인 기록→다음날 복귀 | 성장보다는 리텐션; 신규 유입과 구분 |
| 4 User-generated | 결과 카드 재해석·영상 | 콘텐츠 도구 없음, 자발적 외부 사용만 |
| 5 Referral | 보상 초대 | 어뷰징·보상 비용 때문에 MVP 보류 |

예시 루프 계수 `K=1인당 공유 0.2 × 공유당 새 방문 3 × 활성화 0.3=0.18`은 추정이다. K<1이므로 폭발적 성장을 가정하지 않는다. 초대와 데일리 공유 유입을 구분하고 빈도 제한은 광고 정책과 분리한다.

## 출시 창

- 공개 전: E1/E4, 8언어 핵심 문구 검수, 복구 훈련, 테스터 10명.
- 첫 30일: 친구 그룹 소규모 공개, 광고 없이 NSM·공정성·끊김 측정.
- 31~60일: 데일리 공유와 허용 커뮤니티 게시, Google 승인 후 제한된 광고.
- 61~90일: 채널별 재방문과 실제 현금 손익 평가. 범위 확장은 별도 승인.

출시 조건은 간파 반례 0, 복구 성공, 필수 언어·정책 페이지, 측정된 서버 용량이다. 노출 수 대신 유입→첫 판→재대결→D7을 본다.

## 결정 사항

유료 광고로 사용자를 사지 않는다. 외부 포털에 게임을 제출하지 않는다.

## 열린 질문

사용자가 참여할 커뮤니티·초기 테스트 그룹과 실제 공유 계수는 미확인이다.
