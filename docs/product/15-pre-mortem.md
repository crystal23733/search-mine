## 상위 주장에 대한 steelman과 반박

순위는 영향×오류 가능성×검증 저렴함의 정성 1~5 척도다.

| 주장 / 점수 | 강한 근거 | 실패 조건 / 가장 싼 검증 / 중단 기준 |
|---|---|---|
| 30초면 이해한다 / 5×4×5=100 | 기존 숫자 규칙에 공격 하나를 더함 | 10명 중 6명 미만 이해 / 종이 예제 / 안내 재설계 |
| 반사가 재미를 만든다 / 5×4×4=80 | 직접 대응과 역전이 있음 | 재대결 40% 미만 / 승인 후 10명 관찰 / 규칙 재설계 |
| 공격을 항상 논리로 간파 가능 / 5×5×2=50 | 제한된 후보를 솔버로 검사 가능 | 반례 1개 / 작은 판 전수 검사 / 공격 적용 중단 |
| 현금 손익분기 가능 / 4×4×3=48 | 기존 장비의 증분비가 낮음 | 28일 R<C / 전력계+실 정산 / 유료 확장 동결 |
| 글로벌 승부가 납득 가능 / 4×4×2=32 | 서버 권위는 일관된 순서를 제공 | 지연 때문에 패배 설명이 반복 실패 / 지역 RTT 테스트 / 매칭·표현 재검토 |

고정 범위와 봇 백필은 개발·초기 동접 위험을 줄인다는 점에서 타당하다. 홈서버 성능, 광고 승인, 실제 사용자 재미는 아직 평가할 수 없다.

## 결정 사항

공정성 실패는 출시 차단 사유다. 미래에 증명할 것이라는 가정으로 공격을 출시하지 않는다.

## 열린 질문

E4에서 공격 후보가 거의 남지 않으면 규칙을 바꿀지 사용자가 승인해야 한다.
