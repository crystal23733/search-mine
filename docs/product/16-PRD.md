# 16. Liar Sweeper PRD

> 입력: [비전](01-vision.md)~[리스크](15-pre-mortem.md). 스킬의 8개 항목을 적용했으며 저장명은 핸드오프 지정값을 따른다.

## 1. 요약

Liar Sweeper는 상대 판의 숫자를 속이고 논리로 지목해 반사하는 웹 1:1 지뢰찾기다. PC와 모바일에서 OAuth 계정으로 4분 대전·친구 방·공식 데일리를 제공하고, 설치·로그인 없이 로컬 봇·데일리 연습을 제공한다. 자체 사이트 광고로 홈서버 현금 운영비를 충당하는 것이 사업 목표다.

## 2. 담당과 의사결정

| 역할 | 담당 | 책임 |
|---|---|---|
| 제품 책임자 | 저장소 소유 사용자 | 범위·설계 승인, 계정·도메인·배포 입력, 최종 제품 판단 |
| PM·설계·개발·PR 리뷰 | Codex / Claude Code | 근거와 가설 구분, 설계·TDD·검증·PR 제출·사용자 위임에 따른 검토·병합·이슈 종료 |
| 테스트 참여자 | 사용자 모집 | 사용성·공정성·재대결 관찰 |

## 3. 배경

기존 솔로·레이스·로그라이크 대체재가 존재한다. 차별화 가설은 숫자 조작과 정확한 지목의 반사다. 기존 코드를 제거한 뒤 설계와 개발 환경을 병합했고 제품 기능을 순차 구현한다. 시장 성장률·매출 예측·재미 검증 결과는 없다.

## 4. 목표와 성공 기준

첫 승인 후 검증 창에서 논리 대전의 반복 가치를 입증한다.

| KR | 측정 창 / 기준 | 해석 |
|---|---|---|
| KR1 학습 | E1 10명 중 8명 이상, 30초 설명 후 올바른 지목 | 초기 사용성 목표 |
| KR2 재미 | E2 10명 중 6명 이상 자발적 재대결 | 작은 표본 판단 |
| KR3 공정성 | M1 작은 판 전수검사·속성 테스트에서 반례 0 | 필수 출시 게이트 |
| KR4 안정성 | 공개 전 복구 훈련 성공, 측정된 동접 용량 문서화 | 필수 출시 게이트 |
| KR5 사업성 | 광고 활성화 후 연속 28일 R≥현금비 C | 목표이며 보장 아님 |

NSM은 [주간 반복 대전 사용자](09-north-star.md)다. 동의 거부·광고 차단 때문에 가치 제공을 제한하지 않는다.

## 5. 세그먼트

첫 타깃은 링크로 짧게 경쟁하는 친구 그룹이다. 다음은 데일리 사용자와 공정성을 평가하는 숙련자다. [가설 페르소나](03-segments-personas.md)를 사용하고, 특정 연령/시장 규모는 미확정이다.

## 6. 가치 제안

친구는 준비 없이 함께 대전하고, 숙련자는 안전한 추론으로 공격에 대응하고, 솔로 사용자는 매일 같은 판에서 기록을 남긴다. [대체재 비교](02-competitors.md)와 [포지셔닝](05-value-positioning.md)의 주장은 공정성·재미 실험으로 검증한다.

## 7. 해결책

### 7.1 UX

언어 랜딩→OAuth(Google·Apple·카카오·네이버)→게임용 닉네임→30초 봇 튜토리얼→친구/빠른 대전→결과→재대결·공유. 데일리는 별도 진입하며 서버 장애 시 캐시된 WASM·봇·데일리 연습을 제공한다. 처음 방문한 기기에 오프라인 캐시가 없으면 오프라인 실행을 보장하지 않는다.

| ID | 기준 |
|---|---|
| NFR01 | Rust 공유 코어, OOP/SRP/SOLID·DIP, TS DI, 도메인 인프라 의존 없음 |

200KiB는 **초기 로딩** 예산으로 제안한다. PixiJS 포함 전체 JS 200KiB 달성은 아직 확인하지 않았으며 게임 청크 예산과 분리한 해석은 설계 승인 대상이다.

### 7.4 가정·제약

공정성·재미·지연·광고수익은 [가정](10-assumptions.md)이다. 동일 판 특성상 플레이어가 자신의 정보를 상대에게 공유하는 위험은 완전히 제거할 수 없다. 공개 데일리의 리플레이 검증은 사람이 풀었다는 보장이 아니다. 서버가 죽은 온라인 대전을 로컬 권위로 이어서 순위에 반영하지 않는다.

## 8. 릴리스

M0 승인→M1 코어→M2 싱글 플레이→M3 온라인→M4 정책/광고→M5 운영 검증→M6 베타 튜닝. [상대 일정](21-roadmap-sprints.md)은 주당 작업시간 확정 후 조정한다.

2차 후보는 코스메틱·보상 광고·랭크·리플레이 공유·비대칭·배틀로얄이며 이번 승인에 포함하지 않는다. 유료 서비스 가입·Cloudflare 계정 변경·도메인 구매는 사용자가 직접 한다.

## 결정 사항

FR01~16과 NFR01~08을 구현 계약으로 사용한다. OAuth와 최소 수집은 [17 인증](../design/17-auth-privacy.md), 화면은 [18 디자인 기준](../design/18-design-layout.md)을 따른다. 변경은 설계/ADR을 먼저 갱신한다.
