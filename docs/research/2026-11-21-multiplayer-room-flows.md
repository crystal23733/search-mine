# 다인전 게임의 방 이용 흐름 조사

2026-11-21 · #243/#244 · 사용자 요청에 따라 공개 공식 화면·개발자 안내를 조사했다. 로그인/타인 방 참가·구매·실제 대전은 수행하지 않았다. 아래는 공개 자료의 기능 확인이며 직접 사용성·성능 시험이 아니다.

## 확인 사실

| 게임 / 공식 출처 | 공개 자료에서 확인한 흐름 | 우리 설계에 적용하는 해석 |
|---|---|---|
| [TETR.IO 공식 게임 화면](https://tetr.io/) | MULTIPLAYER 아래 CUSTOM GAME의 공개/비공개 방 생성, ROOM LISTING의 공개 방 참가, 방 ID/URL 입력, 플레이어/관전 구분과 START 조작이 존재한다. | 대전 진입에서 방 찾기·만들기·초대 참가를 나란히 제공한다. 로비와 실제 라운드를 분리한다. |
| [Jstris 개발자 가이드](https://jstris.jezevec10.com/guide) | Lobby에서 방 목록을 보고 Create Room/Private로 비공개 방을 만든 뒤 링크를 공유한다. 관전/참가를 전환할 수 있고 공격 대상을 순환·무작위 등으로 분배한다. | 초대와 공개 발견을 함께 지원하고, 진행 중 새 입장은 다음 판을 기다리게 한다. 공격 분배는 게임의 명시 규칙으로 다룬다. |
| [Jstris 개발자 변경 이력](https://jstris.jezevec10.com/about/versions) | 방장이 나가면 소유 역할을 넘기며 방 인원/설정을 목록에서 파악하는 기능이 설명되어 있다. | 방장 이탈이 모두의 게임 종료를 뜻하지 않게 한다. 인원·정원·진행 상태를 방 카드에서 보여준다. |
| [Minesweeper Together 개발자 소개](https://store.steampowered.com/app/3550060/Minesweeper_Together/) | 온라인 최대8명, 협동/versus를 지원한다. versus는 먼저 판을 완료하거나 높은 점수로 승부한다. | 다인 지뢰찾기와 레이스 자체는 이미 존재한다. 우리 차별화는 숫자 조작·안전한 간파·원래 공격자 반사와 반복 대전 경험이라는 가설이다. |
| [Minesweeper Online 공식 PvP 화면](https://minesweeper.online/pvp) | PvP 진입과 등급 조건·시즌 표시가 있다. | 지뢰찾기 PvP의 존재를 확인했다. 로그인 뒤 방 생성/정원/상세 규칙은 이 자료로 확인하지 못했다. |

TETR.IO의 페이지에는 여러 화면의 정적 요소도 포함된다. 표시된 메뉴는 확인했지만 현재 로그인 상태의 버튼 활성 조건·실서버 최대 인원·실제 매칭 대기 시간은 확인하지 않았다. SEGA 온라인 매뉴얼은 수집 환경에서 지원하지 않는 브라우저 안내가 나와 근거에서 제외했다. 커뮤니티 위키·검색 요약만으로 게임 규칙을 확정하지 않았다.

## 적용과 판단

사용자의 의도는 **홈 → 방 목록/만들기/초대 → 같은 방 대기 → 준비 → 시작 → 결과 → 같은 방 다음 판**으로 해석한다. 무작위 매칭과 초대 코드만으로는 공개적으로 모여 반복하는 경험이 부족하다.

초기 인원은 사용자가 선택한2~4명이다. 사용자가 기존 규칙·첫 완주 때 종료·나머지 안전칸 수 순위·무작위 상대 공격을 직접 지정했다. 따라서 테트리스의 쓰레기 줄·탈락제·99명·전적 파일 다운로드를 옮기지 않는다. 계정/동의/광고/온라인 비밀은 기존 제품 원칙을 따른다.

공개 방이 있어도 신규 사용자가 늘거나 재미가 입증되는 것은 아니다. #27의 첫 초대 성공·규칙 이해·재대결/이탈 관찰과 #26의 실제 장비/회선 검수로 판단한다. [상세 설계](../design/20-multiplayer-rooms.md)와 [ADR0110](../adr/0110-multiplayer-rooms-and-rankings.md)을 따른다.
