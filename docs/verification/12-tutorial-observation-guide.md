# #12 튜토리얼 이해 관찰 준비 — E1, TS13

이 문서는 실제 참여자 관찰을 준비한다. 자동 테스트는 Rust 공격·지목·반사·중복·skip/replay·언어·저장소 경계를 검증하며 사람의 이해·재미를 입증하지 않는다. E1/E2 실행과 원자료는 [#27](https://github.com/crystal23733/search-mine/issues/27)에서 기록하고, 그 전까지 [M2](https://github.com/crystal23733/search-mine/milestone/3)의 해당 출구 조건은 미확인이다. 사람 이름·연락처·OAuth 계정 없이 임의 관찰 번호만 쓴다.

## 관찰 절차

1. 참가자가 사용하는 언어와 PC/모바일 종류를 기록한다. 새 브라우저 프로필에서 locale 홈으로 들어가 최초 학습을 실행한다. 기존 계정이나 비밀번호를 요구하지 않는다.
2. 첫 안내가 표시된 때부터 시간을 재고 설명을 보충하지 않는다. 참가자가 C3 열기→공격→C1 열기→지목을 직접 선택하는지, 안내 버튼/보드/모드 중 어느 경로인지 기록한다. 도움을 주었다면 시간과 내용을 적는다.
3. 완료 뒤 “왜 C1의 2가 틀렸는가”, “정확한 지목이 공격자에게 어떤 효과를 주는가”, “일반 대전의 게이지는 얼마인가”를 자신의 말로 설명하게 한다. 정답 숫자 외 공개 증거와 2초 반사, 학습1/일반20 구분을 각각 기록한다.
4. 30초 안에 처음 공격·지목을 실행했는지와 실제 설명 정확도를 따로 기록한다. 단순 버튼 완료를 이해 성공으로 계산하지 않는다. skip/막힘/실패/재시도/지원 요청도 분모에 포함한다.
5. 학습 다시 하기와 3난이도 로컬 대전 중 원하는 경로를 선택하게 한다. UI 막힘·보드 스크롤·모드 혼동·언어 문구와 다음 대전 의향을 기록한다. 네트워크 단절은 캐시 이후 #14에서 별도 검사한다.

## 기록 형식

| 항목 | 기록 |
|---|---|
| 관찰 번호·언어·기기·빌드 commit | 익명 번호, 실제 환경 |
| 학습 시작→첫 공격/지목/완료 시간 | 각 실제 초, skip 포함 |
| 공개 증거 설명·반사 설명·일반 게이지 구분 | 정확/부분/오해와 짧은 발언 |
| 지원·실패·재시도 | 실제 경로와 오류 |
| 다음 대전 선택·의향 | 실제 선택, 질문 답변 |

실행 뒤 #27에 표본 수·모집 편향·실패 포함 분모·개별 익명 원자료·실제 시간 분포를 연결한다. 30초 목표나 성공률은 아직 측정하지 않았다. 저장소 거절 시 탭 메모리로 skip/completion이 유지되고 새 탭에서는 유실될 수 있다는 안내도 관찰한다. 학습 완료는 일반 match 완료/공식 기록/광고 빈도에 포함되지 않는다.
