## 실행 결과 (2026-11-16)

- 이름 변경 전 관련 웹 테스트에서 접근성 이름·SEO title·공유 title 3개 실패를 확인했다. 변경 후 같은 11개 테스트가 통과했다.
- 긴 이름으로 390px 화면의 가로 넘침을 재현했다. 모바일 로고 글자 크기를 조정한 뒤 8언어 및 360/390/768/1024/1440px 검사와 로고/조작 영역 비겹침 검사가 통과했다. PC·모바일 캡처도 확인했다.
- 전체 웹 479개, 관련 PC/모바일 브라우저 20개, 최종 레이아웃 2개 검사 통과. typecheck/lint/format, 제품 빌드, 문서·Mermaid 검사를 실행해 통과했다.
- 생성 manifest의 name/short_name은 새 이름이며 id/scope/start_url은 `/`이다. 생성 HTML 57개에서 새 이름을 확인했다. 8언어 JSON은 설치/계정의 기존 다섯 문구만 변경했다.
- diff에서 저장소/캐시/쿠키/DB/Compose/service/package 식별자 변경과 비밀값 노출이 없음을 확인했다. 실제 OS의 기존 설치 이름 갱신 및 제공자 콘솔은 운영자 검수로 남긴다.

첫 배포 CI는 변경된 이름을 검사하기 전, 새 동의 문서에서 합성 Google SDK가 준비되기 전에 재열기 버튼을 누르는 경쟁 조건으로 실패했다. 준비 완료 경로를 검사하는 fixture에서 TCF listener 등록을 기다린 뒤 클릭하도록 동기화했다. 재시도/제한 시간/기대값이나 제품 코드는 바꾸지 않았다. 후속 CI 결과는 #237과 연결 PR에 기록한다.
