# #248 다인전 방과 순위 화면

[다인 방 설계](../design/20-multiplayer-rooms.md) 및 [ADR0110](../adr/0110-multiplayer-rooms-and-rankings.md)의 FR01/07/08/10~14/17/18과 TS13/18~26/30~45를 웹과 인증 복귀 경로에 연결했다.

| 흐름 | 실행 근거 |
|---|---|
| 방 목록과 초대 | 공개 목록 요청의 인증 정보 제외와 목록 응답 제한을 서비스 테스트로 확인한다. 실제 PostgreSQL과 HTTPS 테스트 서버에서 초대 전용 방을 만들고, 다른 브라우저의 OAuth 테스트 콜백과 닉네임·튜토리얼을 지나 같은 코드로 복귀한다. 링크를 열거나 로그인만 한 경우에는 입장하지 않는다. |
| 새 라운드와 순위 | 준비한 두 브라우저에서 개인 판을 열고 완주하면 1·2위가 표시된다. 새로고침해도 같은 방과 결과, 다음 판 준비를 표시한다. 실제 서버의 네 계정 WebSocket 테스트는 늦게 들어온 사용자에게 이전 판 결과를 보내지 않고, 방을 나간 참가자의 닉네임을 가린다. |
| 응답과 연결 권한 | 늦은 폴링 응답·이전 경기 순번을 무시하고 로그아웃 시 개인 상태를 지운다. 같은 로그인으로 탭을 추가해도 기존 탭에서 경기를 계속하며, 그 탭을 닫으면 다른 탭에서 재접속한다. |
| 화면 경계 | 8개 언어의 공개 방 제목과 목록이 360·390·1440px 화면 폭에 들어온다. 초대 코드를 키보드로 제출할 수 있다. 초대 문서는 `no-referrer`, 광고 태그 0, 결과 화면은 파일 다운로드 0을 검사한다. |

온보딩 복귀에는 다음 PostgreSQL 마이그레이션을 적용한다. 테스트 OAuth는 로컬 제공자 테스트 어댑터를 사용한다. 4인 브라우저 재대결 및 장애 시나리오까지 묶은 통합 검증은 #249에서 진행한다.
