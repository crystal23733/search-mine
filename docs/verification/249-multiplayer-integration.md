# #249 다인전 통합 검증

[다인 방 설계](../design/20-multiplayer-rooms.md)와 [ADR0110](../adr/0110-multiplayer-rooms-and-rankings.md)의 TS37~45를 Rust 규칙, 실제 서버·PostgreSQL, 배포 빌드 브라우저에서 검증한다.

| 시나리오 | 실행 경로 |
|---|---|
| TS37~39 공개 목록·초대·준비·시작 | 브라우저 네 계정과 비로그인 방문자. 공개 목록에서 참가하고 4/4의 정원 제한을 확인한다. 준비를 취소하면 방장 시작이 비활성화된다. [앞선 브라우저 검사](248-multiplayer-rooms-web.md)에서 초대 링크와 OAuth·온보딩 복귀를 확인했다. |
| TS40~41 같은 판·한 명 공격·반사·순위 | 브라우저마다 본인 판 하나와 상대 세 명의 요약을 받는다. 무작위로 선택된 한 명의 숫자가 바뀌며 간파 후 원래 공격자만 기절한다. 방장이 나가면 다음 방장이 이어받는다. 첫 완주, 두 공동 2위, 중도 이탈을 결과와 본인 전적에서 확인한다. Rust 테스트는 고정 난수로 대상 범위, 중복 공격과 게이지, 원래 공격자 반사를 검증한다. |
| TS42 진행 중 참가·같은 방 재대결 | 3인 경기 도중 참가한 네 번째 계정은 현재 판과 순위를 받지 않는다. 같은 코드의 방에서 네 명이 다시 준비하여 새 라운드를 시작한다. 새 참가 좌석의 입력 순번은 0부터 시작한다. |
| TS43 최소 공개와 권리 | 네 연결에서 타인의 보드, 계정 ID, 난수 시드, 초대 코드와 공격 출처·대상 식별자가 없는지 검사한다. [실제 서버와 PostgreSQL 검사](247-multiplayer-runtime.md)에서 늦게 입장한 계정의 결과 거절, 이탈 후 이름 가림, 만료, 계정 삭제 뒤 공동 순위 유지와 DB 결과를 확인한다. |
| TS44 이동·언어·PWA·광고 | 360·390·1024·1440px에서 방 흐름을 검증하고 게임/결과에서 광고 태그와 다운로드 링크를 찾는다. [#248](248-multiplayer-rooms-web.md)의 8언어 검증과 기존 PWA 설치·오프라인·갱신 회귀를 함께 실행한다. |
| TS45 장애·기존 모드 | 실제 서버로 초기 연결 누락, 같은 방 대기 복구, 프로세스 종료·재기동 뒤 장애 결과와 기록을 검사한다. 기존 1대1·봇·데일리·랭킹·내 정보는 전체 브라우저 회귀에 포함한다. |

브라우저는 테스트 OAuth 제공자와 작은 고정 판을 사용한다. 실제 운영 제공자 로그인은 #42, 운영 Google 동의·자동광고는 #147, 홈서버·백업·용량은 #24~26, 사람 플레이테스트와 실제 OS 설치는 #27/#223에 남긴다.
